# Rat Race Homebrew Tap

```bash
brew tap ratrace-llc/tap
brew install ratrace
```

Or in one step:

```bash
brew install ratrace-llc/tap/ratrace
```

`Formula/ratrace.rb` is regenerated by `make release VERSION=vX.Y.Z` in
[ratrace-cli](https://github.com/ratrace-llc/ratrace-cli) — binaries are hosted
on ShiftStack storage (`https://shiftstack.ai/dl/ratrace/...`). Don't edit the
formula by hand.

## After install

1. Mint a token: [app.ratrace.ai](https://app.ratrace.ai) → Integrations → **Rat Race CLI** → Connect
2. Wire into Claude Code / Cursor / Grok:

```bash
ratrace install --token rr_… --api-url https://app.ratrace.ai
```
